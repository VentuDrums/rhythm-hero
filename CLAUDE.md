# Rhythm Hero

Juego web para aprender lenguaje musical rítmico con palmas. Especificación: `SPEC.md`. Plan: `tasks/plan.md` y `tasks/todo.md`.

- Read CONSTRAINTS.md before writing code. Do not weaken it to make a change pass.
- Antes de dar una tarea por terminada: `npm run check` en verde. Si tarda más de 90 s, avisar a Carlos.
- Carlos es profesor de música, no programador: explicaciones en español, claras y sin jerga.
